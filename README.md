# Guoqing Wang's Homepage

A responsive academic homepage, published with GitHub Pages.

- `index.html`: biography, news, publications, education, and experience.
- `assets/css/style.css`: desktop and mobile styles.
- `assets/js/main.js`: active section indicator in the navigation. All content remains available without JavaScript.
- `imgs/`: portrait and institution logos.

Preview locally by opening `index.html` in a browser, or run `python3 -m http.server 8000` and visit `http://localhost:8000`.

Edit the HTML to update content. News before July 2024 is kept in an expandable archive. Publication links should point to a specific paper or project; the incomplete original OccTrans paper link is omitted until its identifier is available.

The layout takes inspiration from [Jiazheng Xing's homepage](https://jiazheng-xing.github.io/), with an original implementation and Guoqing Wang's own content and assets.
